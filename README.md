## Ezt a projektet készítette Gargya Dániel *(DaniVagyok482)* és Serdült Mátyás *(smatyashu)* 

## Az alkalmazás célja

A program egy konzolban megnyitható kis játék. Az egész C# nyelvben lett megírva, és a lényege az, hogy a ConsoleColor-ban megtalálható színek segítségével lehet rajzolni.

### A program futtatása
Szükséges hozzá a .NET 8.0 SDK (Visual Studio 2022 vagy a dotnet parancs).
Visual Studióval
> Nyissa meg a .csproj fájlt, és indítsa el az F5 gombbal, vagy a CTRL+F5 gombkombinációval hogy hibakeresés nélkül fusson

## Billentyűk és azok funkciói: 

### Az alap rajzolón belüli
**M:** A főmenü megnyitása

**Escape:** Kilépés a kódból

**Space:** A rajzecset felemelése/letétele

**Nyilak:** Mozgás a rajzfelületen belül

**F1-F3:** X alakzat kirajzolása 3x3, 5x5, 7x7 nagyságban

**F4-F6:** Kereszt alakzat kirajzolása 3x3, 5x5, 7x7 nagyságban

**F7-F9:** Négyzet alakzat kirajzolása 3x3, 5x5, 7x7 nagyságban

**F10:** Gyémánt alakzat kirajzolása 3x3 nagyságban

**F12:** Gyémánt alakzat kirajzolása 7x7 nagyságban

**R:** A radírecset mód bekapcsolása/kikapcsolása
**S:** A szivárvány mód bekapcsolása/kikapcsolása

### A főmenün belüli
**Vízszintes Nyílak:** Amint bemegyünk egy adott választási helyre, így tudunk választani az opcióink közül

**Enter:** Adott opció kiválasztása
